# Synthetic example outputs

All result files are generated by `python scripts/evaluate_synthetic.py` from the bundled synthetic inputs, except the selected held-out test-case register, which is extracted from the generated classifier evaluation CSV.

- `demo_reconciliation_matches.csv`: candidate links, deterministic R1-R6 states, exception labels and human decision field.
- `demo_unmatched_internal.csv` / `demo_unmatched_external.csv`: records without a proposed counterpart.
- `demo_duplicate_groups.csv`: duplicate business-key groups.
- `demo_evidence_ledger.csv`: answerability states and source quotes for external confirmation notes.
- `demo_sentence_screening.csv`: sentence-level binary detector and multi-label exception suggestions, with context and offsets.
- `prototype_test_cases.csv`: 15 selected phrase-family-held-out classifier examples, including correct single-label, correct multi-label and five failure cases.

The current trade demo has 13 synthetic records on each side. Current results are 3 exact matches, 9 review candidates, one unmatched record per side and one duplicate group. These counts are not accuracy or savings estimates.
